# 홈페이지 방문 및 상담 클릭 측정

운영 홈페이지 `healimbd.com`만 GA4 웹 스트림 `G-VT6QHEM9MR`에 연결합니다.
개발 빌드에서는 태그를 출력하지 않고, 운영 빌드도 다른 호스트에서는 실행하지 않습니다.
Firebase 회원 인증·문의 저장과 독립적으로 실행합니다.

## 측정 항목

| 이벤트 | 의미 |
| --- | --- |
| `page_view` | 공개 페이지 조회 |
| `phone_click` | 대표전화 링크 클릭 |
| `kakao_click` | 분당점 카카오 채널 링크 클릭 |
| `naver_booking_click` | 분당점 네이버예약 링크 클릭 |

클릭은 전화 통화, 상담 접수, 예약 완료 또는 실제 내원을 뜻하지 않습니다.
네이버예약·카카오에서의 완료 여부는 홈페이지 코드만으로 확인할 수 없습니다.

## 병합 후 확인

1. 운영 홈페이지 배포 후 광고 차단이나 브라우저 추적 거부가 없는 브라우저로 방문합니다.
2. GA4 실시간 보고서에서 `page_view`를 확인합니다.
3. 각 상담 링크를 눌러 해당 클릭 이벤트가 기록되는지 확인합니다.
4. 필요한 경우 GA4 관리에서 세 클릭 이벤트를 주요 이벤트로 지정합니다.
5. 트래픽 획득 보고서의 세션 소스/매체와 클릭 이벤트를 함께 비교합니다.

실제 GA4 수신은 계정의 실시간 보고서 확인이 필요합니다. 구현 테스트에서는 Google로
실제 테스트 데이터를 보내지 않고 태그 및 이벤트 전송 내용을 검증합니다.
설치 이전 방문은 소급 수집되지 않습니다. 일별 보고서는 처리 후 확인합니다.

## AI 유입의 해석

ChatGPT 등에서 참조 주소가 전달되거나 알려진 `utm_source`가 포함되는 방문은
출처를 식별할 수 있습니다. 출처 정보가 없는 앱·복사한 링크·직접 방문은 AI 유입인지
판단할 수 없습니다. 일반 Google 유입만으로 Gemini 또는 AI 요약 유입이라고 분류하지 않습니다.
실제 내원 경로는 초진 시 별도 질문으로 확인합니다.

## 수집 범위

이름, 이메일, 전화번호, 상담 내용, 로그인 정보, 문의·후기 식별자를 읽거나 전송하지 않습니다.
페이지 주소의 쿼리·해시, 외부 참조 주소의 경로·쿼리를 제거하고, 비공개 문의·후기는
섹션 경로로 집계합니다. 임의의 검색어·캠페인 문구를 전달하지 않습니다.
광고 개인화·Google Signals를 사용하지 않으며 분석 쿠키 만료는 90일입니다.
브라우저의 Do Not Track 및 Global Privacy Control 신호가 있으면 GA 태그를 로드하지 않습니다.
GA4 향상된 측정은 현재 비활성 상태를 유지합니다. 자동 폼/검색/외부 링크 측정을 별도로
활성화하면 이 코드 밖의 수집이 추가될 수 있으므로 사용하지 않습니다.

설정에서 `analytics.enabled: false`로 바꾸면 태그 출력을 중지할 수 있습니다.
