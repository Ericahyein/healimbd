# 기존 칼럼 편집 수정 — 2026-10-16

한의 진료를 보조·보완으로 규정하는 표현, 한방 치료 병행을 기존 처방 의료진의 허가 대상으로 읽히게 하는 표현, 반복된 약물 경고, 출처 범위를 부정문으로 강조하는 문장과 “일반 의료기관” 명칭을 정리했다.

총 40편, 문단·요약·FAQ·소제목 71곳을 수정했다. 각 글의 주제에 맞게 실제 진찰 내용과 개인별 한약·침구·생활 관리 계획을 설명하며, 필요한 약물 조정·상호작용·원인 감별 및 응급 안내는 유지했다. 최초 발행일·제목·주소·이미지·작성자·검수 상태·대표 질환 연결과 외부 출처 링크는 보존하고 수정일을 갱신했다. 기존 표도 유지했다. 삭제한 판교 야뇨증은 복구하지 않는다.

전체 64편은 공통 편집 기준으로 검사한다. 자동 생성 규칙에서 사용하는 동일 검사를 기존 원고에도 적용해 수동 수정 시의 재발을 방지한다. 기록된 수정은 개별 원장 검수 완료를 의미하지 않으며 작성자·검수 상태는 변경하지 않았다.
