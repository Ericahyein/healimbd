# 질환 상세페이지 작성·검토 정보와 증상 기록 안내

9개 질환 페이지는 의료 콘텐츠팀 작성과 내용 수정일을 표시합니다.
본문의 기록은 형식을 설명하는 가상의 예시이며 실제 환자 사례나 진단 결과가 아닙니다.
처방, 검사 수치별 판단, 훈련 선택 기준 등 분당점의 세부 치료 노하우는 추가하지 않습니다.

## 실제 원장 검토 완료 후

원장님이 해당 페이지의 의료 내용을 실제로 확인했을 때만 다음 front matter를 기록합니다.

```yaml
medical_review_status: "reviewed"
medical_reviewer: "손지웅 대표원장"
medical_reviewed_at: "YYYY-MM-DD"
```

날짜는 실제 검토한 날로 입력합니다. 예시의 YYYY-MM-DD를 그대로 사용하지 않습니다.
작성자 author는 실제 작성 주체를 유지합니다. 검토했다고 원장 작성으로 바꾸지 않습니다.
현재 9개 문서는 확인된 검토 기록이 없으므로 source_based 상태로 둡니다.
이는 과거에 검토하지 않았다는 판단을 뜻하지 않습니다.

lastmod는 내용 수정일입니다. 의학적 검토일로 자동 변환하지 않습니다.
상태·검토자·유효한 검토일이 모두 갖춰진 경우에만 화면과 검색엔진의 reviewedBy/lastReviewed에 표시합니다.
잘못된 날짜, 미래 검토일, 해당 Person 엔티티와 다른 검토자는 표시하지 않습니다.
후속 의료 내용 변경은 다시 확인을 받고 검토 정보를 갱신하거나 source_based로 되돌립니다.
디자인·띄어쓰기 수정으로 검토일을 새 날짜로 바꾸지 않습니다.

## 확인

- 9개 질환의 작성·수정 정보와 FAQ/본문이 서버에서 출력되는지 확인합니다.
- 기록 예시 9개와 새 FAQ 9개는 기존 질문·방문 준비 안내를 보완합니다.
- 실제 검토 기록 없이 화면이나 JSON-LD에 원장 검토를 선언하지 않습니다.
- 검토 기록이 있는 테스트 문서에서는 수정일과 검토일이 서로 다른 값으로 유지되는지 확인합니다.
