# 자동발행 칼럼 품질 점검 — 2026-10-01

최근 자동발행 13개 글과 발행 이력 37개를 점검했다. 이 점검은 글과 생성 설정의 문제를 확인한 것으로, 검색 노출 저하의 원인을 확정하거나 순위 상승을 보장하는 자료는 아니다.

## 확인한 문제와 수정

- 식후 어지럼증 글에 번아웃 설명이 길게 섞이고, 긴장형 두통 글에 PPPD 자료가 중심 근거로 사용됐다. 두 글을 주제에 맞게 다시 작성하고 공식기관·논문 출처를 본문 설명에 연결했다.
- 최근 글 8개에 확인되지 않은 상담 경험·내원 빈도 표현이 있었다. 독자가 겪을 수 있는 상황을 설명하는 문장으로 바꿨다.
- 작업 중 추가된 강박증 글에도 우울증·번아웃 자료가 붙어 있었다. 강박증의 NIMH·NHS 자료로 교체하고 번아웃 독립 설명을 삭제했다. 생성 설정도 강박증 주제와 우울증 주제를 구분했다.
- 최근 실신 글의 두 출처 링크는 같은 ESC 지침이었다. 별도의 NHS 실신 자료를 안전 대처 설명에 연결했다.
- 위 12개 글은 실제 개별 의사 검수를 확인하지 않았으므로 의료 콘텐츠팀의 공개 출처 기반 정리로 표시한다. 기존 URL, 최초 발행일, 이미지는 유지한다. 수정한 식후 어지럼증 글의 제목·키워드·이력 제목을 일치시켰다.

## 앞으로의 자동발행

- 하루 2건, 성남·분당·판교·용인·경기광주 5개 지역, 같은 질환의 3일 간격을 유지한다. 지역+질환을 45일간 금지하는 규칙은 추가하지 않는다.
- 기존 35개 세부 주제 중 30개가 사용됐고, 질환+주제 조합 7개가 여러 지역에서 반복됐다. 발행 이력에 있는 질환+주제를 지역이나 경과 시간과 무관하게 제외한다. 기존 제목·본문·FAQ 유사도 검사는 유지한다.
- 새 세부 주제 40개를 추가했다. 현재 주제는 총 75개, 아직 사용하지 않은 주제는 45개다. 유한한 주제 목록이므로 소진 전에 새 주제를 검토·추가해야 한다. 남은 후보가 없으면 중복 주제를 재사용하지 않고 발행을 중단한다. 이력이 손상돼도 빈 이력으로 간주하지 않는다.
- 출처를 주제에 맞게 선택한다. 번아웃, 미디어 노출, PPPD 등 특정 주제 자료는 해당 주제에서만 사용한다. ADHD의 소아 주제에는 소아 평가 자료를 사용할 수 있게 했다.
- 서로 다른 검증 출처 2개 이상을 본문 설명에 연결해야 한다. 실제 API 생성 결과에서 빠진 링크를 자동으로 참고자료 목록에 덧붙여 통과시키지 않는다. 미검증·부족한 출처는 검사를 통과하지 못한다.
- 검사 안내는 뇌인지검사, 뇌기능검사, 정서심리검사, 문진·설진·복진·진맥을 필요에 따라 활용하는 범위다. HRV·심박변이도·자율신경 반응도 검사와 확인되지 않은 상담 경험은 차단한다. 뉴로피드백·밸런싱·IM은 틱장애·ADHD에서 평가 후 선택적으로 활용하는 범위로 제한한다.
- 새 글에 개별 검수 완료나 원장 직접 작성 표시를 자동으로 붙이지 않는다. 질환 상세페이지가 있는 주제는 해당 페이지 링크를 유지하며, 두통 등 상세페이지가 없는 주제는 진료과목 안내를 사용한다.

## 검증 범위와 한계

주제별 출처·검사 사실·출처 누락 차단·지역 간 재발행 차단을 테스트했다. 14일간 하루 2건의 주제 선택을 모의 검증했으며 실제 OpenAI 호출이나 발행은 하지 않았다. 기존 제목 재시도, 91.4%/96.8% 제목 충돌, 본문·FAQ 유사도, QA, 내부링크 및 정적 페이지 렌더링 검증을 함께 수행한다.

출처 URL과 주제 태그 검사만으로 모든 의학 설명의 정확성과 출처의 의미 일치를 판정할 수는 없다. 실제 검수와 최근 발행 글 점검은 계속 필요하다. 기존 글을 삭제하거나 일괄 noindex 처리하지 않는다.

기존 `test_auto_column_system.js`의 옛 썸네일 디자인 검사(`heavy-text-shadow`)는 변경 전 main에서도 실패한다. 이번 수정에서 썸네일 디자인을 바꾸지 않았으며, 현재 CI의 별도 썸네일 회귀 검사를 사용한다.
