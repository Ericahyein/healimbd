# 자동 칼럼 편집 기준 — 2026-10-20

한의 진료가 다른 치료의 보조 수단이거나 기존 처방 의료진의 허가를 받아야 시작하는 진료처럼 읽히던 표현을 정리한다. 한의 진료의 실제 과정과 역할을 직접 설명하며, 의학적 사실이나 필요한 안전 안내를 제거하는 방식으로 해결하지 않는다.

## 작성 기준

- 진료 소개는 증상 경과·수면·소화·피로·정서 상태를 어떻게 확인하고 개인별 한약·침구·생활 관리 계획을 정하는지 설명한다. 본원에서 제공하지 않는 검사·시술이나 확인되지 않은 효과·기전을 만들지 않는다.
- 한의학적 평가·체질 진찰·한약·침구를 일괄적으로 “보조적”, “보완적”, “보조 요법”으로 규정하지 않는다. 다른 치료와 대체 불가를 비교하는 관성적인 부정문도 피한다.
- 현재 복용약은 진료 시 확인한다. 기존 약의 변경·감량·중단을 위한 협의와 한의 진료 자체의 병행 여부를 구분한다. 기존 처방 의료진의 사전 허락·승인을 한의 진료의 조건처럼 쓰지 않는다. 상호작용·이상반응·금기나 약물 조정 등 구체적 필요가 있으면 관련 의료진과 협의한다.
- 일반적인 약물 임의 중단 경고를 요약·본문·FAQ에 반복하지 않는다. 필요한 진료 준비 안내 한 곳에서 간결하게 다룬다. 구체적인 위험·상호작용 안내와 응급·감별 안내는 유지한다.
- 공개 칼럼에는 논문·지침·기관명과 외부 URL, 참고문헌 목록을 넣지 않는다. 검증된 의료 지식은 내부 작성 참고에만 사용하고, 개별 연구 결과나 수치의 출처가 불확실하면 해당 주장을 생략한다. 응급·감별·복약 안전 안내는 유지한다.
- 약물 유지·변경·중단 검토 권고를 한의 진료 병행의 허가 요건으로 확대하지 않는다. 확인되지 않은 치료 효과를 주장하지 않는다.
- 다른 진료과 안내는 “일반 의료기관” 대신 필요한 진료과와 평가 목적을 구체적으로 적는다.

## 복용약 안내 예시

현재 복용 중인 약이 있다면 진료 시 알려주세요. 아이의 증상과 복용 약을 함께 살펴 한약·침구 치료 등 개인별 진료 계획을 세웁니다. 기존 약의 용량이나 복용 방법을 조정할 필요가 있다면 처방 의료진과 협의합니다.

누구에게나 모든 약과 한약을 함께 복용해도 안전하다고 보장하거나, 기존 약의 임의 중단을 권하는 의미로 사용하지 않는다.

## 반영 위치와 검증

공통 기준은 `scripts/auto_column/editorial_policy.js`에서 관리한다. 본문 생성 프롬프트, 주제별 의료 지식 준비, 생성 결과 검증, 게시 직전 검사, 텔레그램 각색 프롬프트와 각색 결과 검사에 연결했다. ADHD·공황·불면·IBS·소아 야뇨증 자료에서 상충하던 FAQ·지침·출처 해석도 함께 정리했다.

새 자동 발행은 `requireCitationFree` 검사를 통과해야 하며, 텔레그램 각색본도 출처 표기를 검사한다. 과거 원고에 출처가 남아 있으면 원문 보존 HTML 복구 경로는 전송을 중단한다. 이전에 발행된 칼럼은 자동으로 수정되지 않는다.

`tests/test_column_editorial_policy.js`는 실제 발행 문제에서 추출한 17개 원문 사례를 차단하는지 확인한다. 복용약 확인, 상호작용에 필요한 협의, 약물 조정 협의, 응급 안내가 허용되는지와 임의 약물 중단 권고가 계속 차단되는지도 확인한다. 웹사이트와 텔레그램의 실제 모델 요청은 가짜 응답으로 검사하므로 외부 발행·전송·모델 사용료가 발생하지 않는다.

검사는 명시적인 문제 표현을 차단하는 장치다. 모든 의미상 유사 표현이나 의학적 정확성을 완전히 판정하는 검수는 아니므로 실제 원고의 문맥 검토는 계속 필요하다. 기존 게시 글은 이번 규칙 변경으로 자동 수정되지 않는다. 삭제한 판교 야뇨증의 발행 이력에는 삭제 상태를 명시해 해당 주제의 자동 재사용 제외와 원고 부재 검사를 유지한다.
