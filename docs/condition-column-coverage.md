# 질환별 칼럼 보강과 자동 발행 우선순위

## 적용 범위

질환 상세페이지가 있는 9개 질환에 직접 연결된 공개 칼럼을 `content/blog`에서 세어, 3개 미만이면 임시 점수를 더한다. 기존 수동 칼럼도 포함하며, 파일 이름이나 제목으로 질환을 추정하지 않는다. 다한증 1개, 미주신경성 실신 1개, 과민성대장증후군 2개인 현재 콘텐츠 공백부터 보강하기 위한 기준이다. 3개는 콘텐츠 운영 목표이며 SEO 또는 AI 추천을 보장하는 수치가 아니다.

- `condition_pillar`가 있으면 해당 질환에만 집계한다. 빈 값·다른 질환·알 수 없는 링크는 공유 분류로 대체하지 않는다.
- 이 필드가 없는 과거 글만 정확히 일치하는 질환 분류로 집계한다.
- 초안, 미래 `date`/`publishDate`, 만료 글과 목록 페이지는 제외한다. 날짜만 적힌 글은 사이트 설정과 동일하게 한국 시간 자정부터 집계한다.
- 질환 상세페이지가 없는 두통·우울·강박·소아 기타 주제에는 추가 점수를 부여하지 않는다. 해당 질환의 기존 발행 기회는 유지한다.
- 소스 디렉터리가 없거나 읽을 수 없으면 발행 후보 선정을 중단한다. 잘못된 0개 집계로 진행하지 않는다.

## 선정 방식

추가 점수는 `max(0, 3 - 공개 칼럼 수) × 60`이다. 기존 지역·질환 조합의 최근 발행 점수, 지역 순환과 동점 후보의 날짜별 순환을 함께 적용한다. 성공한 다음 발행에서는 새 Markdown을 다시 세므로, 3개에 도달한 질환은 추가 점수가 0이 되어 기존 순환 방식으로 돌아간다. 특정 질환의 우선순위를 영구히 고정하지 않는다.

다음 제약은 추가 점수보다 먼저 적용한다.

1. 하루 2개까지 발행하며 같은 날 같은 질환을 다시 선택하지 않는다.
2. 같은 질환은 한국 날짜 기준 최소 3일 간격을 지킨다.
3. 이미 발행한 질환·주제는 다른 지역에서도 재사용하지 않는다.
4. 의료정보 기준이 승인되어 있는 질환만 선택하고, 생성·검증에서 거절된 후보와 주제는 재시도에서 제외한다.
5. 모든 후보가 소진되면 기존 글을 재포장하지 않고 중단한다.

자동 발행 시간, 승인된 5개 지역(성남·분당·판교·용인·경기광주), QA 기준, 자동 병합/배포 설정은 기존 설정을 따른다. 즉시 새 칼럼을 발행하는 작업은 포함하지 않는다.

## 기존 글과 겹치지 않는 보강 주제

현재 주제 라이브러리에는 다음과 같은 미발행 주제가 이미 있으며, 발행 이력과 재시도 제외 항목에 따라 실제 선정 주제는 달라진다.

| 질환 | 현재 직접 연결 칼럼 | 보강 가능한 주제 예시 |
| --- | ---: | --- |
| 다한증 | 1 | 갑자기 땀이 늘었을 때 확인할 점, 발한 부위와 생활 불편 기록 |
| 미주신경성 실신 | 1 | 전조 증상과 대응, 가족이 목격한 당시 상황 기록 |
| 과민성대장증후군 | 2 | 식사 일지, 복통과 배변 양상의 관계 |

2026-10-02 오후 17:07 한국 시간과 현재 main 이력을 기준으로 첫 후보는 `gyeonggi-gwangju-hyperhidrosis-sudden-sweat-change`다. 미주신경성 실신은 2026-09-30 발행 이력이 있어 10월 3일부터 간격 조건을 충족한다. 후보 선택은 발행 성공이나 시간을 보장하지 않으며, 이후 생성·출처·유사도 검증 결과에 따라 바뀔 수 있다.

## 다한증 대표 글 보강

기존 URL과 최초 발행일은 유지한다. 제목과 발행 이력의 제목, 동일 주제의 제목 템플릿을 ‘수술 후 보상성 다한증이 걱정될 때 확인할 점’으로 통일한다. 수술 전 상담과 수술 후 변화 평가를 구분하고, 기록 표와 공식 학회 자료의 본문 설명을 추가한다.

- AAD 진단·치료: https://www.aad.org/public/diseases/a-z/hyperhidrosis-treatment
- AAD 증상: https://www.aad.org/public/diseases/a-z/hyperhidrosis-symptoms
- BAD 환자 안내: https://www.bad.org.uk/pils/hyperhidrosis

공식 자료는 일반 다한증·수술 정보를 뒷받침하며 한약·침구 치료의 보상성 발한 예방/제거 효과로 확대 해석하지 않는다. 이번 수정본의 개별 의료진 검수가 확인되지 않았으므로 공개 출처 기반 작성 범위를 표시하고 검수자·검수 날짜를 새로 만들지 않는다. 자동 생성용 다한증 자료에도 같은 제한과 주제별 공식 자료를 연결한다.

## 검증

`node tests/test_condition_column_coverage.js`는 공개 글 집계, 초안/예약/빈 pillar 배제, 부족한 질환 우선순위, 두 선정 함수의 일치, 제외 주제 재시도, 하루 2개·3일 간격·5개 지역·중복 방지, 14일 발행 모의시험과 3개 도달 후 점수 해제를 확인한다. 모의시험은 임시 디렉터리에 발행 파일을 추가하며 운영 콘텐츠와 이력을 변경하지 않는다.

Hugo 빌드 후 `node tests/test_condition_column_coverage.js public`은 글 제목과 상세페이지의 대표 카드, 기록 표, 작성 범위, 최초/수정 날짜, Article 구조화 데이터를 함께 확인한다. 두 검증은 PR 자동 검사에 포함한다.
