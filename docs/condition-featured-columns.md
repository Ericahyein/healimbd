# 질환별 대표 칼럼과 최신 관련 글

각 질환 상세페이지의 `featured_column`에 먼저 보여줄 기존 칼럼 주소를 1개 지정합니다.
대표 글은 새 글이 발행되어도 첫 번째 카드에 유지됩니다. 나머지 두 자리는 같은 질환의
최신 발행 글로 채우며 대표 글을 중복 표시하지 않습니다.

```yaml
featured_column: "/blog/bundang-tic-disorder-brain-balance-treatment/"
```

현재 선택은 최근 보강한 글과 질환별 기존 글 중에서 이루어졌습니다.
‘대표 칼럼’은 홈페이지의 읽기 순서이며, 개별 의학적 검토 완료나 치료 성과를 뜻하지 않습니다.

- 같은 질환의 발행된 칼럼만 선택합니다. 명시된 `condition_pillar`를 우선합니다.
- `condition_pillar`가 없는 이전 글은 `column_categories`로 연결합니다.
- 주소가 없거나, 초안·미래 글·다른 질환·칼럼이 아닌 페이지이면 대표 표시를 생략합니다.
- 글이 1편이면 1개, 2편이면 2개만 보여줍니다. 다른 질환의 글로 빈 칸을 채우지 않습니다.
- 카드 제목은 현재 글 제목에서 지역 접두어만 제외합니다. 별도 제목 사본을 유지하지 않습니다.
- 대표 글을 교체할 때는 위 주소만 수정합니다. 발행 일정·주제 로테이션과 의료 본문은 별도입니다.

검증: `HUGO_BIN=/path/to/hugo node tests/test_condition_column_links.js`
