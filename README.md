## 🚀 빠른 시작 (Quick Start)

### 로컬 개발 서버 실행
```powershell
hugo server -p 1313 --bind 127.0.0.1
```
* 웹 브라우저에서 `http://localhost:1313/` 접속

### 정적 빌드 생성
```powershell
hugo --minify -d public
```

### GitHub 업로드
* 바탕화면의 **`해아림_깃허브업로드.bat`** 더블 클릭 또는:
```powershell
git push -u origin main
```
